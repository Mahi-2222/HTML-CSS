PUSHING AND CLONING A REPOSITORY From inside html-lab, create a bare repository beside it: git init --bare ../html-remote Connect and push: git remote add origin ../html-remote git remote -v git push -u origin main If your branch is named master instead, use: git push -u origin master Go one folder up and clone the repository: cd .. git clone html-remote html-copy cd html-copy git log --oneline The cloned repository should contain the same commits.
